# APPRESSO - APLICACIÓN DE GESTION DE VENTAS DE CAFETERÍA
*******************************************************

Aplicativo diseñado para una cafetería y gestión de la misma.
En este aplicativo se busca aprender conceptos de programación avanzada como:

- Bases de datos estructurada (Reforzamiento)
- Consultas y queries optimizadas (BigO y Complejidades de datos)
- Recursividad de Codigo
- Validaciones de datos y al envio de datos
- Seguridad y cifrado de los datos
- Registros de Logs mas precisos
- Interfaces HTML, CSS y React (TSX)
- Uso de NodeJS con NestJS
- Uso de Nodos (Por reforzar)
- Uso de Ventana Deslizante (Por revisar)

*******************************************************
# STACK TECNOLÓGICO DEFINIDOI POR MI
*******************************************************

- Se usara BD PostgreSQL, debido a que una base de datos estructurada para este caso es mas facil de manejar y en caso de escalabilidad de facturas o ventas, los metadatos JSON que nos permite guardar la BD lo hace mas dinamica y facil de usar.ult_actualizacion
- Se usara Diseño HTML + CSS con Framweork React, necesario con NodeJS
- Arquitectura Data, Business, UI, separado por capas como se usa tradicionalmente. (Database, BackEnd, FrontEnd)
